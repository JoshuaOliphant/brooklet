# DEC-009: Python 3.12+ Minimum

**Status:** Accepted

## Context

Need to choose a minimum Python version that balances modern features with adoption.

## Decision

Require Python 3.12 or later.

## Consequences

- Access to modern Python features (improved error messages, performance)
- Broad enough support (3.12 and 3.13 tested in CI)
- No need for compatibility shims with older versions
